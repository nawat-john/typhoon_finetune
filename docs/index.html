5ลองรันเอง

ต้องมี GPU CUDA + Python 3.10–3.12 Clone repo แล้วรันตามนี้: 

# ติดตั้ง
pip install torch --index-url https://download.pytorch.org/whl/cu124
pip install unsloth transformers datasets trl peft bitsandbytes accelerate
pip install yt-dlp youtube-transcript-api google-genai python-dotenv

# ดึงข้อมูล + เทรน
python scripts/list_videos.py
python scripts/fetch_transcripts.py --target-hours 8
python scripts/clean.py && python scripts/restore_punct.py
python scripts/build_dataset.py
python scripts/train.py --epochs 2

# คุย
python chat.py
📌

ใช้ YouTuber คนอื่นได้ — เปลี่ยน channel ID ใน list_videos.py pipeline ที่เหลือทำงานได้เหมือนเดิม เหมาะกับช่องพูดคนเดียว (vlog, cast, podcast)
